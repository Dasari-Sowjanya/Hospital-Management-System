# 🏥 Hospital Management System

A console-based **Hospital Management System** developed using **Core Java** to manage essential hospital operations such as patients, doctors, appointments, pharmacy, billing, and blood bank services.

## 🚀 Features

- Patient Registration & Login
- Patient Profile Management
- Doctor Management
- Appointment Booking
- Pharmacy & Medicine Management
- Billing & Payment Management
- Blood Bank & Blood Requests
- Input Validation & Authentication

## 🛠️ Technologies Used

- Java
- Core Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Date & Time API

## ▶️ How to Run

```bash
javac HospitalManagementSystem.java
java HospitalManagementSystem
